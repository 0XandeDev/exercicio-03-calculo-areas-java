
# Exercício 03 - Cálculo de Áreas em Java

## Sobre o projeto
Programa desenvolvido em Java que permite ao usuário escolher entre calcular a área de um quadrado ou de um círculo por meio de um menu interativo.

## Funcionalidades
- Exibe um menu com duas opções de cálculo.
- Calcula a área de um quadrado.
- Calcula a área de um círculo.
- Solicita os valores necessários para realizar os cálculos.

## Conceitos praticados
- Entrada de dados com Scanner.
- Estruturas condicionais (if e else).
- Operações matemáticas.
- Utilização de constantes e variáveis.
- Lógica de programação.

## Fórmulas utilizadas
- Quadrado: área = lado × lado.
- Círculo: área = π × raio².

## Tecnologias utilizadas
- Java
- IntelliJ IDEA

## Objetivo
Praticar os fundamentos da linguagem Java por meio
da criação de um menu e da realização de cálculos matemáticos.
